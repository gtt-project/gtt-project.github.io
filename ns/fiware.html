GTT FIWARE core vocabulary (retired)

This vocabulary (https://gtt-project.org/ns/fiware#, with the context files fiware.jsonld and fiware-task.jsonld) was retired on 2026-10-11, before it had users outside the project.

GTT's data models are now published at models.gtt-project.org. The redmine_gtt_fiware plugin sends Redmine issues as Issue entities: datamodels.jp's Task under Redmine's name, plus the issue category.

  • @context: https://models.gtt-project.org/context/redmine/v0.jsonld
  • Terms: https://models.gtt-project.org/ns/redmine
